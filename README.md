# Python Notes App 📝

A simple command-line Notes App built with Python. This project allows users to save notes to a text file and view them later.

## Features

- View saved notes
- Add new notes
- Save notes in a text file
- Keep notes between program runs
- Simple menu-driven interface

## Requirements

- Python 3
- A code editor, such as VS Code
- Command Prompt or another terminal

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the program:

   ```bash
   python test.py
   ```

   If your Python file has a different name, replace `test.py` with that filename.

## How to Use

1. Run the program.
2. Choose **1** to view saved notes.
3. Choose **2** to add a new note.
4. Choose **3** to exit the application.

## File Handling

This project uses Python file handling to store and retrieve notes.

- `"r"` reads saved notes.
- `"a"` adds new notes without deleting existing ones.
- `with open()` helps ensure files are properly closed.
